### Comunicación entre agentes quedó formalizada

Ahora la arquitectura establece explícitamente:

```text
Agent Communication
│
├── Semantic Layer
│   ├── Task
│   ├── Message
│   ├── Result
│   ├── Artifact
│   ├── Progress
│   ├── Failure
│   └── Cancellation
│
├── Protocol Layer
│   ├── Internal Protocol
│   ├── A2A
│   └── Custom Protocol
│
├── Transport Layer
│   ├── In-process
│   ├── HTTP
│   ├── Webhook
│   ├── WebSocket
│   ├── SSE
│   ├── gRPC
│   ├── Queue
│   ├── Kafka
│   └── Service Bus
│
└── Reliability Layer
    ├── Ack
    ├── Retry
    ├── Timeout
    ├── Deduplication
    ├── Idempotency
    ├── Ordering
    ├── DLQ
    └── Backpressure
```

La regla constitucional quedó:

> **Agents communicate through explicit semantic contracts independent of protocol and transport. Protocols define interoperability; transports define delivery; neither belongs inside the Agent Core.**

### Actualicé también las reglas de escritura

Agregué reglas obligatorias para que cuando escribamos los capítulos no terminemos mezclando conceptos. Por ejemplo, ya no podremos dibujar:

```text
Webhook → AgentLoop
```

sino:

```text
Webhook
   ↓
TriggerAdapter
   ↓
ActivationRequest
   ↓
Admission
   ↓
Routing
   ↓
ExecutionTarget
```

Y tampoco:

```text
Agent A → WebSocket → Agent B
```

como arquitectura semántica. WebSocket es transporte. Primero debe existir el contrato de comunicación.
